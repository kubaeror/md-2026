# Compatibility

## Required

- **Hearts of Iron IV 1.19.x**
- **Millennium Dawn: A Modern Day Mod 2.0.0** (Workshop ID 2777392649)

The submod's `descriptor.mod` declares `supported_version="1.19.*"` and
`dependencies = { "Millennium Dawn: A Modern Day Mod" }`, so the launcher loads it after MD.

## Architecture

- No `replace_path` is used. MD's own bookmarks, focus trees, characters, technologies and
  events stay untouched wherever the submod does not need to extend them.
- Files that extend MD content are **generated** from the installed MD version plus the 2026
  patches (see [Architecture](Architecture.md)). They are refreshed with
  `python tools/rebase.py generate`.
- New content uses the `md2026_` prefix (ideas, decisions, events, scripted effects, opinion
  modifiers, localisation).

## Files that override Millennium Dawn

| Path | What is overridden | Regenerated by |
|---|---|---|
| `common/national_focus/<md file>` | MD focus trees with an injected `MD2026_*` branch | `rebase.py focus` |
| `history/countries/<md file>` | MD country history + 2026 block (66 countries) | `rebase.py history` |
| `history/states/<md file>` | MD state history + 2026 ownership (7 states) | `rebase.py history` |
| `common/scripted_effects/md2026_technology_effects.txt` | not an override (new file), generated from MD's tech tree | `rebase.py tech` |

Everything else is additive.

## Game version compatibility

| HoI4 | Status |
|---|---|
| 1.19.x | Supported (Millennium Dawn 2.0.0) |
| 1.17.x | Not supported (pre-rebase version of this submod) |

## DLC compatibility

The technology tiers mirror Millennium Dawn's own DLC gating, so the submod works with any DLC
combination Millennium Dawn supports. When a DLC is missing, the corresponding techs are simply
not granted (`if = { limit = { has_dlc = "..." } }` blocks).

Army orders of battle currently ship in the `_nsb` variant (No Step Back). Without NSB the 2026
bookmark falls back to Millennium Dawn's 2000 OOB for that country - see
[Known Issues](Known-Issues.md).

## Other submods

The submod conflicts with other submods that override the same MD files (the focus trees and
country/state history listed above). Additive submods (new events, decisions, focus trees with
different file names, GFX/music) are compatible.
